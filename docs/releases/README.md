# Publication records

Keep one dated record per deliberate release, linking its exact source,
workflow, APK identity/checksum, and web deployment evidence. Record any later
feed/documentation-only commit as intentional runtime parity.

Rolling Preview identity is authoritative in the verified GitHub release and
production update feed. Historical records do not authorize a stable/F-Droid
update. Follow [the release procedure](../RELEASE-CHANNELS.md).
